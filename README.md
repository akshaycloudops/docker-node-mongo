# 🚀 Dockerized Node.js + MongoDB App (AWS EC2)

This project is a simple Node.js application connected with MongoDB, fully containerized using Docker and deployed on AWS EC2.

---

## 📌 Features
- Node.js backend (Express)
- MongoDB database
- Docker + Docker Compose setup
- Deployed on AWS EC2
- REST API endpoints

---

## 🏗️ Architecture

Client → EC2 → Docker → Node App → MongoDB

---

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- Docker
- Docker Compose
- AWS EC2 (Ubuntu)
