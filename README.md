# Docker Node.js + MongoDB App (AWS Deployment)

## Overview
This project is a simple Node.js API connected with MongoDB, fully containerized using Docker and deployed on AWS EC2.

## Tech Stack
- Node.js
- MongoDB
- Docker
- Docker Compose
- AWS EC2 (Ubuntu)

## Features
- REST API with Node.js
- MongoDB database connection
- Dockerized services (App + DB)
- Publicly accessible via EC2
